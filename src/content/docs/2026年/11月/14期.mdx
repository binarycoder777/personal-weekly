<div align="center">
<img src="https://www.rust-lang.org/static/images/rust-social-wide.jpg" width="400" alt="" loading="lazy" />

### [为什么系统编程选择 Zig 而非 C](https://www.mtsoukalos.eu/2026/11/why-zig-over-c-for-systems-programming/)

作者认为 Zig 与 C 同样贴近机器且无 GC，但 errdefer 让资源清理紧邻分配并按逆序执行，便于用 FailingAllocator 测试每条失败路径；Zig 直接调用 C 库并使用 C ABI。作者仍喜爱 C，但不愿再用 C 写新代码。

---

### [Relax：减少 Rust 构建等待的 JIT 编译器](https://makepad.github.io/relax/)

Relax 是实验性 Rust 实时编译器/JIT 运行时，直接从源码运行 Cargo 包，无需 rustc、LLVM 或链接器；按函数首次调用编译、热函数运行中优化，并热补丁编辑保留状态。优化代码比 release 慢约 1.12×（x64）/1.24×（arm64），仅用于开发迭代。
