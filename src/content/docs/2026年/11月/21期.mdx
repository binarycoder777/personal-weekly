### [Nginx 存在未认证远程代码执行漏洞](https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities)

<div align="center">
<img src="https://www.datocms-assets.com/75231/1794936719-img_7875.png?fm=webp" width="400" alt="" loading="lazy" />

Wiz 等团队发现两个 NGINX HTTP/2 严重漏洞 CVE-2026-123633 与 CVE-2026-123007，CVSS 4.0 评分 9.2，可未认证远程执行代码。影响超 2.25 亿网站，即使应用代码安全也可能暴露，利用需启用 HTTP/2。F5 已于 11 月 18 日发布修复，建议尽快升级。

### [别买内存，压缩它！](https://curiousbits.nl/blog/do-not-buy-ram-compress/)

<div align="center">
<img src="https://curiousbits.nl/static/blog/do-not-buy-ram-compress/apps.png" width="400" alt="" loading="lazy" />
</div>

作者在 32GB 内存的 Linux 工作站上因并行任务耗尽内存，改用 zram 内存压缩后获得最高约 1:4 的压缩比。文章指出 Windows、macOS 与部分 Linux 发行版已默认启用，Ubuntu 等则没有；压缩仅增加少量 CPU 开销和延迟，却能显著降低云主机扩容成本。

### [群晖发布安全公告](https://www.synology.com/en-uk/security/advisory/Synology_SA_26_21)

<div align="center">
<img src="https://fileres.synology.com/images/common/meta-tag-preview-image/img_synology.jpg" width="400" alt="" loading="lazy" />
</div>

群晖披露 DSM 与 BeeStation OS 中的严重漏洞 CVE-2026-120382，CVSS 3.1 评分 9.8，属 OAuth API 命令参数定界符处理不当，可被远程攻击者利用读写任意文件并发动拒绝服务。DSM 7.4/7.3 已修复，7.2 等仍在处理中；缓解措施为停用 OAuth Service 套件。
